# 躲避大师 - 抖音小游戏上架指南

## 🎮 游戏介绍

**游戏名称：** 躲避大师

**游戏类型：** 休闲益智 / 反应类

**游戏简介：** 
一款简单上瘾的躲避类小游戏。玩家需要控制屏幕底部的小球，左右移动躲避从上方掉落的彩色障碍物。游戏难度会随着时间逐渐增加，考验玩家的反应能力和手眼协调能力。

**游戏特色：**
- 🎯 简单易上手，适合全年龄段
- 🎨 精美的UI设计和流畅的动画效果
- 📈 渐进式难度，挑战无极限
- 🏆 实时计分系统，激发竞技欲望
- 📱 完美适配移动端，支持触摸控制

## 🚀 上架流程

### 第一步：登录开发者平台
访问 https://developer.open-douyin.com/ 并登录

### 第二步：创建应用
1. 进入"应用管理"
2. 点击"创建应用"
3. 选择"小游戏"类型
4. 填写应用基本信息

### 第三步：上传游戏包
1. 将游戏文件打包为ZIP格式
2. 上传至开发者平台
3. 等待平台审核（通常1-3个工作日）

### 第四步：填写资质信息
1. 上传软著证书
2. 填写ICP备案号
3. 上传版号（如需要）
4. 提交审核

### 第五步：测试上线
1. 通过审核后，先发布到测试环境
2. 进行内部测试
3. 确认无误后，发布到正式环境

## 📝 注意事项

### 内容规范
- ❌ 不得包含暴力、色情、赌博等内容
- ❌ 不得侵犯他人知识产权
- ✅ 确保游戏内容健康向上
- ✅ 遵守《网络短视频内容审核标准细则》

### 技术要求
- 游戏包大小建议不超过20MB
- 首屏加载时间不超过3秒
- 兼容主流手机屏幕尺寸
- 支持离线运行（至少一个关卡）

1. **社交分享：** 集成抖音分享功能，让玩家分享成绩

4. **活动运营：** 定期举办活动，保持游戏热度
