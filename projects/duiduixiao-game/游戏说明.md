# 躲避大师 - 游戏说明文档

## 📱 游戏概述

**游戏名称：** 躲避大师  
**版本：** 1.0.0  
**开发技术：** HTML5 + Canvas + JavaScript  
**适配平台：** 抖音小游戏、微信小游戏、H5网页  

## 🎮 游戏玩法

### 基本操作
- **移动控制：** 手指在屏幕上左右滑动，控制小球移动
- **目标：** 躲避从屏幕上方掉落的彩色障碍物
- **失败条件：** 小球与任何障碍物发生碰撞

### 游戏机制
1. **计分系统：** 每成功躲避一个障碍物得1分
2. **难度递增：** 每得10分，障碍物下落速度增加
3. **障碍物生成：** 随机位置、随机颜色、随机大小
4. **游戏结束：** 碰撞后立即结束，显示最终得分

### 关键技术点

#### 触摸控制
```javascript
// 触摸开始
handleTouchStart(e) {
    this.touchStartX = e.touches[0].clientX;
}

// 触摸移动
handleTouchMove(e) {
    const touchX = e.touches[0].clientX;
    const deltaX = touchX - this.touchStartX;
    this.player.x += deltaX * 0.8;  // 平滑移动
}
```

#### 碰撞检测
```javascript
checkCollision(obs) {
    return (
        this.player.x < obs.x + obs.width &&
        this.player.x + this.player.width > obs.x &&
        this.player.y < obs.y + obs.height &&
        this.player.y + this.player.height > obs.y
    );
}
```

#### 难度递增
```javascript
// 每10分增加难度
if (this.score > 0 && this.score % 10 === 0) {
    this.obstacleSpeed = 3 + Math.floor(this.score / 10) * 0.5;
    this.obstacleSpawnRate = Math.max(30, 60 - Math.floor(this.score / 10) * 3);
}
```

## 📊 性能优化

### 已实施的优化
1. **Canvas优化：** 使用requestAnimationFrame替代setInterval
2. **对象池：** 障碍物移除时从数组删除，避免内存泄漏
3. **边界检查：** 玩家移动限制在屏幕内
4. **事件节流：** touchmove事件使用preventDefault减少默认行为
